# 出血 （bleeding）
## 为什么需要出血
由于平面设计在工业印刷或裁剪后，由于设备原因裁剪可能有误差，为了避免裁剪对原设计造成的影响，预留裁剪空间的设计策略称为**出血**，预留的被裁剪区域称为 **出血区**，**全出血设计（Full bleed layouts）** 则是指设计稿预留裁剪区，大于实际设计尺寸的方法。

## 知识点
1. 出血是指在平面设计时，预留尺寸的设计方法
2. 出血的类型
   1. **内出血** 按照平面材料尺寸添加额外尺寸设计
   2. **外出血** 按照实际尺寸设计，流出空白区域
