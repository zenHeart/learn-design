## 跨书籍共性：设计认知的四层模型

几乎所有经典最终都落在同四个问题上。这就是本站知识地图的骨架来源：

### 第一层：理解用户为什么这样行为（心理层）

- 用户的头脑里有一幅对系统如何运作的"蓝图"（心智模型），设计的任务是让界面匹配它，而不是教育用户适应界面（Norman、Yablonski 热门划线最高频主题之一）[E]。
- 人在看、读、记、注意上都有系统性偏差与容量上限（Weinschenk、Miller、Hick），设计是对这些限制的补偿。
- 共识操作：用熟悉的隐喻与既有产品约定（雅各布定律），把复杂度留给系统（特斯勒定律），组块化组织信息（米勒定律）。

### 第二层：好设计的行为特征（原则层）

四本不同背景的书给出高度收敛的判断：

- **可感知**：功能必须可见、可发现（Norman 的示标；Nielsen 启发式 1"系统状态可见性"同源）。
- **有反馈**：每个操作都有及时、明确的结果告知（Norman 反馈；多赫蒂阈值给出 400ms 时限）。
- **不思考**：界面自解释，符合约定与直觉（Krug；雅各布定律）。
- **能容错**：限制错误发生 + 让恢复容易（Norman 设计心理学 4；波斯特尔定律"输出保守，输入多元"）。
- **有秩序**：视觉上用对比、重复、对齐、亲密性建立层级（Williams CRAP；Refactoring UI 把它工程化为间距/灰阶尺度）。

### 第三层：从想法到界面的路径（流程层）

- Garrett 五层模型（战略→范围→结构→框架→表现）与英国设计协会双钻模型（发散→收敛 ×2）、GV Design Sprint 是同一件事的三种表述：**先明确问题与约束，再收敛到具体界面；每一层都有对应产物**。
- Krug 的补充：不要试图在纸面上一次做对——可用性测试要早做、多做、廉价地做，一个早上、三个用户就能发现大部分严重问题。

### 第四层：可用之上是情感与意义（体验层）

- Norman 三层次：本能层（外观第一印象）、行为层（使用的掌控感）、反思层（使用后的记忆与自我认同）。美化界面提升的正是本能层——这解释了审美-可用性效应：**用户认为美观的设计更易用**（weread 热门划线 x64，美学易用性章节）[E]。
- 原研哉提供另一个维度：克制、"白"、留白本身就是信息设计，反对装饰堆砌。

## 对本站的直接推论

1. 心理层证据已沉淀在 `principles/lawsofux.md`（26 法则）；视觉秩序进一步细化为 CRAP 四原则后并入 principles 层。
2. 流程层不是"设计师的仪式"，而是 agent 审视一个产品时的**提问顺序**：先问它在战略层想达成什么，再逐层向下检查——这是 README 中"专业设计师视角审视"场景的方法论来源。
3. 任何具体产品类型（patterns 层）的设计约束，都可以向上追溯到这四层中某一层的具体化。新增内容时用这个映射决定放置位置。
