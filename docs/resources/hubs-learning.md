## 建立个人"高信噪比"设计输入工作流

许多前端工程师困扰于"想提升设计品味，但不知道平时看什么、怎么看"。以下是推荐的信息摄取节奏：

### 1. 深度文章类（每月精读 2-3 篇）
* **大厂工程与设计复盘**：重点关注 **Airbnb Design**、**Uber Design** 和 **Linear Readme**。这些团队产出的文章往往包含完整的问题定义、设计探索分支、踩坑权衡以及最终的代码/组件系统落地，能够极大扩充你对复杂工程系统设计的认知宽度。
* **专业架构刊物**：**Stripe Increment**（系统软件与设计架构期刊）与 **Smashing Magazine** 的设计系统长篇专题，适合在周末或技术研讨会期间研读。

### 2. 前沿技术与视觉技巧（每周浏览）
* **CSS 表现力与交互极限**：关注 **Lynn Fisher** 与 **Bram.us**。了解现代浏览器最新规范（如 CSS Anchor Positioning、Scroll-driven Animations、View Transitions）在极致交互体验中的最新应用。
* **本土化与无障碍深耕**：**腾讯 CDC** 与 **张鑫旭博客** 提供了极其详实的中文字体排版、深色模式适配、边界场景兼容性与可用性实战方案。

### 3. 法则与可用性实证速查
* 当你在实际需求中对某个组件的交互行为（例如弹窗层级、表单校验时机、列表空状态）产生疑问时，第一时间去 **NN/g（Nielsen Norman Group）** 搜索相关研究报告。NN/g 的文章基于真实用户的眼动仪测试与任务完成度实证，远比同事之间的"主观感觉"更有说服力。

## 规范与国际标准快速检索

除设计团队博客外，本站涉及的核心规范与无障碍基线推荐直接查阅官方现行权威标准：

- **W3C 中文排版需求 (clreq)**: <https://www.w3.org/TR/clreq/>（字距、标点挤压、行高比例标准）
- **Web Content Accessibility Guidelines (WCAG) 2.2**: <https://www.w3.org/TR/WCAG22/>（对比度、触控热区、键盘导航基线）
- **W3C DTCG Format (2025.10)**: <https://design-tokens.github.io/community-group/format/>（设计令牌跨平台规范）
- **The Component Gallery**: <https://component.gallery>（全球主流开源设计系统的组件命名与变体形态全量交叉索引）
