## 这是什么

面向 agent 与工程师的设计知识站点，服务于三类高频判断场景：

1. **判断现有设计是否有问题**（design review）——按 ② 判断依据层的检查链走查
2. **按某个设计风格重构**（style refactor）——按 ④ 参照体系层选型后映射落地
3. **以专业设计师视角审视**（professional critique）——按 ③ 方法流程层的提问顺序 + ① 认知入口层的四问框架

完整的知识地图、agent 使用指南与扩展约定见仓库 [README](https://github.com/zenHeart/learn-design#readme)。

## 引用纪律

- 凡涉及版本、状态、数值的论断均带取用日期（当前快照：2026-09-02）
- 事实性论断挂来源（L0 官方 / L2 行业 / E 实证）；厂商自测数据标注"声称"
- 三次点击法则、"必须全放首屏"、7±2 菜单上限等已证伪教条在 ⑤ 层有专表，审稿时主动排除
