# 可用性启发式与无障碍基线

> 与 [lawsofux.md](lawsofux.md) 互补：lawsofux 是心理学视角的法则集合，本文是「评审 checklist 视角」的两套硬性框架——Nielsen 十启发式（专家走查依据）与 WCAG 关键数字（合规底线）。
> 取用日期：2026-09-02；来源层级 L0（nngroup.com、w3.org）。

## Nielsen 十大可用性启发式

来源：<https://www.nngroup.com/articles/ten-usability-heuristics/>（Nielsen & Molich 1990 提出，1994 年精炼为现版；2020 年更新措辞与示例，**十条本身自 1994 年以来未变**，仍是当前版本）

| # | 启发式 | 一句话评审问句 |
|---|---|---|
| 1 | 系统状态可见性 | 操作后系统是否立刻告知"发生了什么" |
| 2 | 系统与真实世界匹配 | 用词与概念是否说用户的语言而非系统语言 |
| 3 | 用户控制与自由 | 误操作是否有明显"退出/撤销/重做"出口 |
| 4 | 一致性与标准 | 同一含义是否在站内外用同一词、同一交互 |
| 5 | 错误预防 | 是在错误发生后报错，还是先让错误难以发生 |
| 6 | 识别而非回忆 | 对象、选项、操作是否可见，用户不必记住上一屏 |
| 7 | 灵活与效率 | 是否为熟练用户提供快捷方式（快捷键/自定义） |
| 8 | 美学与极简设计 | 界面上每一处信息是否都与当前任务相关 |
| 9 | 帮助用户识别、诊断并从错误中恢复 | 报错是否用用户语言说明问题+给出解决方案 |
| 10 | 帮助与文档 | 帮助是否易于搜索、面向任务、上下文相关 |

**用法**：专家走查时逐条问一遍界面；每条都能对应到 lawsofux 中的心理学根源（如 #6 识别而非回忆 ← 认知负荷；#4 一致性 ← 雅各布定律）。

## WCAG 无障碍关键数字

来源：<https://www.w3.org/TR/WCAG22/>（WCAG 2.2，2023-10-05 发布 Recommendation，2024-12-12 更新一次；已纳入 ISO/IEC 40500。**WCAG 3.0 仅有 early draft，尚未取代 2.x**，引用无障碍基线以 2.2 为准）

| 项 | AA 级数值 | 说明 |
|---|---|---|
| 正文文本对比度 | ≥ 4.5:1 | 18pt（约 24px）或 14pt 粗体以上为"大文本" |
| 大文本对比度 | ≥ 3:1 | — |
| 非文本对比度（图标/控件边界/焦点指示） | ≥ 3:1 | WCAG 2.2 强化的 1.4.11 条目 |
| 焦点可见性 | 必须可见 | 2.2 新增 2.4.11 焦点不遮挡（Focus Not Obscured） |
| 拖拽替代 | 必须提供单指针替代 | 2.2 新增 2.5.7（Dragging Movements） |
| 目标尺寸最小值 | ≥ 24×24 CSS px | 2.2 新增 2.5.8（Target Size Minimum）；增强级 SC 2.5.5 为 44×44（AAA，沿自 2.1） |
| 一致帮助 | 同一位置提供帮助入口 | 2.2 新增 3.2.6 |

- 等级关系：A < AA < AAA（AAA 对比度要求 7:1 正文）。行业基线是 **AA**，多数平台规范（如 Windows 触控目标 40+ epx、iOS 44pt）在 2.2 的 24px 最低值之上更进一步。
- 与产品规范的关系：平台自有规范（Fluent/HIG/Material）的无障碍条款通常映射到 WCAG，冲突时以 WCAG 为合规底线、平台规范为日常依据。

## 与其他层的关系

- 平台差异化的无障碍实现（键盘/屏幕阅读器/文本缩放）放各设计语言与产品模式文档，本文只维护跨平台通用的硬数字。
- Microsoft Win32 UX Guide 的对比度条款（4.5:1 / 大文本 3:1）与 WCAG 一致，其 UX checklist 中的"Top Violations"适合作为桌面应用走查的补充清单（见 Windows 桌面研究笔记，本地提取物待正式入库）。
